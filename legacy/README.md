# Original workspace

This folder preserves the previous pnpm workspace and its API, database,
generated clients, sandbox, scripts, and Replit configuration.

The active React app is now in the repository root. Use the root README and
`package.json` to install, run, and build it. The packages in this folder are
not part of the root npm project. Their former workspace-relative paths are
retained for reference; this folder is not configured as a separate runnable
copy of the website.
